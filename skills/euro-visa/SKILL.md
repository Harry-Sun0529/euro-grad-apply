## 这个命令做什么

从"拿到 offer"到"在当地安顿下来"的执行清单：接受 offer → 签证 → 行前 → 落地前 30 天 → 长期身份路径。

## 必问清单（先问再答，一次最多 3 个）

1. **目标国家**（必问）：签证类型、资金证明额度、落地流程各国差异极大
2. **在哪个阶段**：还在选 offer / 已接受待签证 / 签证办理中 / 即将出发 / 已落地
3. **是否带家属**：配偶 / 子女随行的资金门槛、等待期、配偶工作权各国差异很大，且**经济成本翻倍**
4. **读硕还是读博**：博士多为雇佣制走工作签证，流程与学生签证不同

## 工作流程

1. 诊断（必问清单）
2. **学位归属最后核对**（用户还在决策期 / 尚未交 deposit 时必做）：
   - 确认 offer 上的**学位授予院系**和**学位证书英文全称**
   - 如果用户有"回国留服要认定成某一类"的硬要求，现在是**最后能改的窗口**——交了 deposit、办了签证再发现不对，代价大得多
   - 跨专业 / 交叉学科（艺术治疗、数字人文、计算社科等）尤其要核
   - 详见 `../euro-grad-apply/references/china-specific-procedures.md` §11
3. 按阶段给对应清单：
   - **决策期**：多 offer 对比（项目匹配 > 排名）、conditional offer 的条件、waitlist 处理、deposit 是否可退
   - **签证期**：该国签证类型 + 资金证明**来源合规性**（比金额更容易被忽视）
   - **行前**：住房（荷兰/爱尔兰/北欧极紧张，offer 一确认就要开始找）、资金、保险、必带原件
   - **落地前 30 天**：住处 → 市政厅注册 → 拿身份号 → 激活银行 → 居留许可（**这个顺序不能乱，前一步是后一步的前置**）
   - **长期**：工签、永居、入籍路径
4. 涉及金融/保险产品时先说免责（见下）

## 必须主动提醒的两件事

**1. 资金证明看的不只是金额，还有来源合规性**

各国规则差异极大，最容易踩的是：
- **瑞典不接受私人个体作为 sponsor**——父母不能担保，钱必须在学生本人名下
- **法国要求材料期限一致**：在读证明 / 资金证明 / 住房证明 / 保险的覆盖期必须对得上
- **德国**：Sperrkonto、父母收入证明、担保声明等多种方式可组合
- 突然出现的大额存款会被怀疑，**提前 3-6 个月让资金到位**

**2. 金融 / 保险 / 银行产品的免责（涉及时第一句就说）**

> 以下供应商对比仅供参考。价格、政策、产品功能每年都在变，且这些选择直接关系到你的财务和健康——做最终决定前必须到官网核对当前条款，并在 Trustpilot / Reddit 等平台看真实用户评价。

不给"最佳推荐"，给不同情况下的选项 + 各自取舍。涉及具体金额、月费时**主动 web search 当前数据**。

## 边界

- **签证金额、资金证明额度、保证金一律以该国移民局官网为准**——具体说明每年可能调整，reference 里的是方向性参考
- 不替用户做金融产品选择；不推荐"最佳"，只给选项和取舍
- 签证被拒的具体原因需看拒信原文，不要凭猜测下结论
- **长期身份边界**：本命令处理拿到 offer 后的签证、居留、行前、落地和身份路径执行；永居/入籍的具体年限与语言要求见 `permanent-residence-and-citizenship.md`，必须以该国移民局或官方法律文本为准。还未进入 offer 后执行阶段的长期身份规划，交由主 skill + `career-goals.md` 做总体比较。
