# 欧洲学术 CV 标准

> 本文是 CV 相关知识的唯一真相源。动机信、推荐信、Research Proposal 见 `materials-guide.md`。

---

## 1. 标准 Section 清单

判断一份 CV「缺什么」的基准。**逐项对照，缺哪个字段就回头问用户，不要自行脑补。**

### 1.1 必备（缺任何一项都要问）

| Section | 最小信息单元 |
|---|---|
| **Personal Info** | 姓名（英文拼写）· 邮箱 · 电话（含国际区号）· 所在城市 |
| **Education** | 学校全称 · 学位（B.Eng./B.Sc./M.Sc.）· 专业 · 起止年月 · **GPA 含满分制** |
| **Research / Work** | 机构 · 职位 · 起止年月 · 2-4 条 bullet（每条须含可核实结果） |
| **Skills** | 分类列出（技术 / 工具 / 方法），不要堆砌无关技能 |
| **Languages** | 语言 + **具体等级或分数**（IELTS 7.5 / German B1），不写「精通」「熟练」 |

### 1.2 条件必备（有就必须列，没有不用编）

- **Publications** — 有任何论文/会议/预印本都要列，**标明作者位置**（如 2/5）和状态（published / under review / in preparation）
- **Thesis** — 本科或硕士毕业论文题目 + 导师，申研究型项目时是重要信号
- **Teaching / TA** — 申博时有加分，助教课程名 + 学期

### 1.3 加分项（有空间才放）

Projects（课程外的独立项目）· Awards & Scholarships · Certifications · Conference presentations · 相关志愿服务

### 1.4 通常删掉

- 兴趣爱好（除非与专业直接相关，如申设计放摄影）
- 高中及以前经历（除非国际奥赛级别获奖）
- 政治面貌、婚姻状况、身高体重
- 「Objective」段落——欧洲 CV 不用，动机信才是讲目标的地方
- 学生会/社团职务占主体（可提一行，不要展开）

## 2. 硕士 vs 博士 CV 的差异

| | 授课型硕士 | 研究型硕士 / 博士 |
|---|---|---|
| 页数 | **1 页**足够 | 1–2 页，有发表可到 2 页 |
| 重心 | 课程匹配 + 实习 | **研究经历 + 方法论 + 产出** |
| Publications | 有则列，无不影响 | **权重最高**，没有也要写清研究经历的方法和结论 |
| Thesis | 可选 | 必列（题目 + 导师 + 一句话结论） |
| Referees | 通常不放 | 部分项目要求，放 2–3 位（姓名 · 职称 · 机构 · 邮箱），**放前必须先征得对方同意** |
| 课程列表 | 可列 relevant coursework | 只列与研究方向直接相关的 |

## 3. Bullet 写作规范

### 3.1 公式

> **具体动词 + 做了什么 + 怎么做（方法/工具）+ 可核实的结果**

### 3.2 动词黑白名单

| ❌ 黑名单 | ✅ 换成 |
|---|---|
| 参与、协助、负责 | 设计、实现、评估、构建 |
| involved in / helped / participated | designed, implemented, benchmarked, analyzed |
| 了解、熟悉、接触过 | （直接写做了什么，不写掌握程度） |

### 3.3 「量化」的三档退让

用户答不出数字时**按档退让，绝不编造**：

1. **有数字** → 「将训练时间缩短 40%」
2. **无数字但有规模** → 「标注并整理了一个 12,000 张图像的数据集」
3. **无规模但有方法与产出** → 「用混合精度重写训练流程，该流程后来被组内另外 3 人复用」

⚠️ **硬约束**：成品 CV 里**绝不允许出现** `[X%]`、`[TODO]`、`[待补充]` 这类占位符。宁可用第 3 档表述，也不留空。

### 3.4 中文经历英译的常见坑

| 中文 | 建议译法 |
|---|---|
| 学生会 | Student Union（不要译成 Student Government，含义不同） |
| 团支书 / 班长 | Class Representative（不解释政治属性） |
| 大创 / 挑战杯 | National Undergraduate Innovation Program / "Challenge Cup" National Competition（加一句括号说明级别） |
| 双一流 / 985 | 不直译，改用可核实的客观表述：`ranked top 1% nationally` 或直接不提 |
| 优秀毕业生 | Outstanding Graduate Award（如有比例，加 `top 5%`） |

## 4. 各国惯例差异

| 国家 | 照片 | 出生日期 | 国籍 | 页数上限 | 备注 |
|---|---|---|---|---|---|
| **德国 / 奥地利** | 惯例上放 | 常见 | 常见 | 2 页 | 传统上还有手写签名，现已少见 |
| **瑞士** | 惯例上放 | 常见 | 常见 | 2 页 | 与德语区一致 |
| **荷兰** | **不放** | 不放 | 可选 | 2 页 | 反歧视规范明确 |
| **北欧（瑞典/丹麦/挪威/芬兰）** | **不放** | 不放 | 可选 | 2 页 | 同上 |
| **法国** | 可放可不放 | 可选 | 常见 | 1–2 页 | Grande École 偏正式 |
| **意大利 / 西班牙 / 葡萄牙** | 常见 | 常见 | 常见 | 2 页 | 惯例接近德语区 |
| **比利时** | 可选 | 可选 | 可选 | 2 页 | 荷语区偏北欧，法语区偏法国 |
| **爱尔兰 / 英国** | **不放** | 不放 | 不放 | 2 页 | 明确反歧视 |

> 各校可能有自己的要求，**以项目官网的 application requirements 为准**。

## 5. 照片规范

**先说结论：照片是惯例，不是硬性要求。不放不会被拒。**

如果目标国惯例上放（见 §4）：
- 证件照标准：正面、纯色背景、职业着装
- 尺寸建议：宽 300–400px，放在右上角
- **不要 P 图**，不要用生活照、艺术照、带滤镜的照片
- 不确定时，查项目官网有无明确说明；没说明就按目标国惯例

## 6. 中国学生高频问题

- **GPA 未标满分制** —— 必须写 `88/100` 或 `3.7/4.0`，**只写 88 或 3.7 是无效信息**。有排名就加 `(Top 8%)`
- **学校层次的表达** —— 不要写 "Project 985 University"（国外招生官不懂）。用 `ranked top 1% nationally` 这类可核实表述，或干脆不提
- **研究经历太笼统** —— 「参与了 XX 项目」等于没写。要写清方法、数据、结论
- **时间格式不统一** —— 全文统一用 `2024.03–2024.12` 或 `Mar 2024 – Dec 2024`，不要混用
- **信息过载** —— 1 页放不下就删，不要缩字号到 8pt。删的顺序：课外活动 > 无关技能 > 弱相关项目
- **中英混排** —— 中文机构名建议 `Shandong University`，需要时括号加中文。不要整段中英夹杂

## 7. 格式与提交

- **提交格式**：PDF（除非系统明确要求 Word）
- **文件命名**：`Lastname_Firstname_CV.pdf`，如 `Zhang_Ming_CV.pdf`。不要用 `简历最终版.pdf`、`cv (1).pdf`
- **字体**：一份 CV 只用 1–2 种字体。正文 10–11pt，姓名 20–24pt
- **页边距**：上下 14–16mm，左右 16–20mm
- **Europass**：**除非目标项目官方明确要求，否则不用**。它的表格式排版在学术申请里普遍不占优势，信息密度低且难以按相关度重排

---

## 8. 往年录取偏好类信息的使用边界

搜索目标项目时可能遇到「去年录了个 GPA 3.2 的」这类社区传闻。

**使用规则：**

- 这类信息**必须标注是社区传闻，不是官方要求**。用户无法区分「官方门槛」和「某人的个案」时，要么盲目乐观要么徒增焦虑
- 传闻**只能影响措辞和排序**（例如得知项目重视工程实践，就把项目经历前移）
- 传闻**绝不能成为隐瞒真实经历的理由**——不能因为「听说他们不喜欢转专业的」就把跨专业背景藏起来。成绩单和推荐信会交叉验证，隐瞒的代价远大于坦诚
- 官方页面没写的要求，**宁可标注「未查到」也不要用传闻填补**
